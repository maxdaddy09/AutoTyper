AutoTyper
=========

Paste text into AutoTyper, click into any window, press a hotkey, and AutoTyper types
the text there as real keystrokes. It works in fields that block pasting.

How to use
----------
1. Double-click AutoTyper.exe. Nothing to install.
2. Paste your text into the big box.
3. Pick how it types:
     Letters - one character at a time.
     Words   - one word at a time.
   Then set the delay in milliseconds, or, in Words mode, tick "Words per minute"
   and set a speed instead.
4. Click into the window you want to type into, then press Ctrl+Alt+T.
   Press it again to stop.

To change the hotkey, click the Hotkey box and press the combination you want.
The hotkey, mode, delay and speed are remembered. The text you paste is never saved.

Windows warning on first run
----------------------------
Windows may say "Windows protected your PC" because this program is not signed.
Click "More info", then "Run anyway".

Good to know
------------
- Windows will not let AutoTyper type into a window running as administrator, unless
  AutoTyper is also run as administrator.
- Windows 11 Notepad has its own spell check and autocorrect, which can rewrite words as
  they are typed, especially misspelled words. Turn those off in Notepad's settings
  if you want exact text there.
- How fast text can be typed also depends on your PC. A 0 ms delay means "as fast as
  Windows allows", not instant.
- AutoTyper only types into the window that has focus when you press the hotkey. It will
  not type into its own window.
